# Project Rules — Novyra Academy AI

These rules apply to all backend implementation work in this repository and override any default behavior that conflicts with them.

1. Use only Node.js, npm, npx, TypeScript, and JavaScript.
2. Never use Python.
3. Never redesign existing UI.
4. Reuse existing components.
5. Use Server Components by default.
6. Use Client Components only when necessary.
7. Follow App Router best practices.
8. Use strict TypeScript.
9. Use Zod validation.
10. Use Prisma ORM.
11. Use PostgreSQL (Neon).
12. Use Auth.js.
13. Keep components reusable.
14. Keep APIs modular.
15. Explain every major change.
16. Run lint after every phase.
17. Never commit secrets.
18. Never modify completed UI without approval.
19. Never use any deprecated APIs.
20. Write production-ready code only.
